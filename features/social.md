# Feature: Social

**Phase:** 3  
**Status:** Spec only — not implemented  
**Code (planned):** `apps/web/src/features/social/`

## Goal

Like, comment, follow — surface people who give good recommendations.

## Acceptance criteria

- [ ] Like playbooks (and optionally places)
- [ ] Comment threads on playbooks
- [ ] Follow users; feed or “from people you follow” filter later
- [ ] Basic profile: display name, bio, cities they post about
- [ ] No public follower graph abuse tools required for MVP

## Out of scope (v1)

- DMs
- Private circles
- Complex reputation scores (simple counts OK)
